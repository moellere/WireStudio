+---------------------------------------------------------------------------------------------------------+
|  ESP32-DevKitC-V4  ---  energy-monitor                                                                  |
+---------------------------------------------------------------------------------------------------------+
|  Rails: 5V, 3V3, GND                                                                                    |
|                                                                                                         |
|  pzem_bus  [Modbus RTU bus protocol (RS485-over-UART)]  -- PZEM modbus                                  |
|    UART  -> pzem_uart (uart)                                                                            |
|                                                                                                         |
|  mains  [Peacefair PZEM-004T v3 AC energy monitor (Modbus RTU over UART)]  -- Heater Circuit            |
|                                                                                                         |
|  clamp  [Current transformer clamp (SCT-013 class, analog)]  -- Dryer Circuit                           |
|    OUT   -> GPIO34                                                                                      |
|                                                                                                         |
|  dcrail  [TI INA219 high-side current/power monitor (I2C)]  -- 12V Rail                                 |
|    VCC   -> rail 3V3                                                                                    |
|    GND   -> rail GND                                                                                    |
|    SDA   -> i2c0 (GPIO21)                                                                               |
|    SCL   -> i2c0 (GPIO22)                                                                               |
|                                                                                                         |
|  Passives:                                                                                              |
|    r_burden: 33R resistor, clamp.OUT  <->  GND   (CT burden (SCT-013-000))                              |
|    r_bias1: 10k resistor, clamp.OUT  <->  3V3   (mid-rail bias)                                         |
|    r_bias2: 10k resistor, clamp.OUT  <->  GND   (mid-rail bias)                                         |
|                                                                                                         |
|  BOM:                                                                                                   |
|    - ESP32-DevKitC-V4                                                                                   |
|    - Modbus RTU bus protocol (RS485-over-UART)  (pzem_bus)                                              |
|    - Peacefair PZEM-004T v3 AC energy monitor (Modbus RTU over UART)  (mains)                           |
|    - Current transformer clamp (SCT-013 class, analog)  (clamp)                                         |
|    - TI INA219 high-side current/power monitor (I2C)  (dcrail)                                          |
|    - 1x 33R resistor                                                                                    |
|    - 2x 10k resistor                                                                                    |
|                                                                                                         |
|  Power: ~11mA typical, ~16mA peak (budget 500mA)  OK                                                    |
|                                                                                                         |
|  Warnings:                                                                                              |
|    [warn] mains_isolation: The PZEM-004T measurement side connects to live mains: enclose it, fuse the  |
|                            voltage tap, and keep the TTL side's optocoupled isolation intact.           |
+---------------------------------------------------------------------------------------------------------+
